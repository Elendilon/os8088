# PaccMan

The `PACCMAN` folder holds PaccMan, the arcade-accurate Pac-Man, and its
notes:

- `PACCMAN.O88`, the game;
- `README.MD`, the notes on the port. Double-click it to read it.

## Where it is

This folder is on the everything set and on the live USB image and CD. On
PaccMan's own disk the same files are at the top level of the disk.

Copy the folder as a whole to move PaccMan to another disk.
