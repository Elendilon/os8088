# Read Me

`README.MD` is PaccMan's read-me, the notes its author keeps beside the
program. It covers where the game comes from (Andre Weissflog's pacman.c,
and the arcade original it follows), the keys and the Game menu, what this
version changes to fit the machine, how each screen adapter lays out the
maze, and how fast it runs, with the measurements. Its words are shown
below.

## Where it is

At the top of the PaccMan disk in every size, and in the `PACCMAN` folder
of the everything set.

## Using it

Open it in ArtfulType, which shows its headings and bold text as styles,
or in Note Pad. Much of it is written for
people building the program from its source, so for playing the game the
PaccMan manual is the shorter read. It was written on a modern computer,
and a few characters, such as long dashes and the section sign, show as
other characters on os8088.
