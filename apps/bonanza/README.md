# Bounce Bonanza for os8088

A native 8086 rolling-ball game: a ball you roll directly over an isometric
course that **hardware-scrolls in both directions** on the two 1983 graphics
cards, the CGA (320x200, four colours) and the Hercules (a 360x200 field of
pair pixels). It is this project's own design, not a remake: the course and
the ball are generated by `tools/bonanza_assets.py` from code, and nothing
else is read at build time or at run time. See SPEC.md 128 and
`docs/plans/BOUNCE-BONANZA-PLAN.md`.

**Status: wave 0, the engine spike.** A generated test course (plateaus,
ramps, steps, pits and walls, a long descent with sections that cross the
whole width), the 64-frame phase-torus ball, and the instruments that price
a frame. There are no heightfield physics, obstacles, sound or game rules
yet: the ball rolls freely and bounces off the course's edges.

Keys, on the desktop: Enter, F or Alt+Enter plays; **B runs the benchmark**
(the autopilot drives a fixed route for 1,200 frames, then the window shows
the frames, the display rate, the refreshes missed and the worst frame, and
the cost of each part of a frame). Playing:
the arrows roll the ball; Esc, F or Alt+Enter goes back to the desktop.

Needs a CGA or a Hercules card (anything else is refused with the reason)
and kern_big or kern_mega; the 128KB machine's kernel refuses it.

Build:

```
make bonanza        # build/bonanza.o88
make bonanzadisk    # build/bonanza.img, bonanza720.img, bonanza120.img, bonanza360.img
make bonanza-check  # the asset generator's own gate
```
