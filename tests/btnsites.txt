# tests/btnsites.txt - the BUTTON registry (SPEC.md 20.5.1.3)
#
# `os88ui_btn` IS the standard button: it takes a RECORD and an index, resolves
# the pressed look from OS88UI_BT_DOWN itself, and its four siblings -
# os88ui_btninit, btnpress, btndrag, btnup - are the SPEC.md 13.7 gesture.
# A caller that uses them cannot fire on the press, cannot forget to install
# W_ONMOUSEUP, and cannot draw a repaint that disagrees with the glass.
#
# `os88ui_btnraw` is the old loose-register painter (rect, label, flags). It is
# the drawing body and nothing else: it knows no gesture, so a caller on it owns
# the whole of SPEC.md 13.6 by hand - which is how TWENTY-FIVE of the tree's
# call sites came to fire on the PRESS with no pressed look at all.
#
# ONE LINE PER FILE: <record> <raw> <path>  # <reason>
#
# A file NOT in this list may not call either - that is the case that matters,
# because it is what a new package hits. A file in it may not exceed either
# count, and may not fall below them either: lowering a `raw` after a
# conversion is the diff saying the work happened.
#
# THIS IS A RATCHET, NOT A CLEAN GATE, and it starts where the tree is. What it
# stops from day one is `raw` going UP - a NEW caller of os88ui_btnraw is a new
# button that fires on the press, which is the defect this whole registry is
# about. docs/plans/BUTTON-GESTURE-PLAN.md 8 is the order to work the rest down
# in.
#
# WHY A GATE AND NOT A SURVEY: docs/plans/completed/UIHELPERS-PLAN.md 15.4 is a
# survey table of exactly this defect, and SEVEN of the ten carriers landed
# AFTER it was written. SPEC.md 13.8.4 predicted that in as many words. A
# survey cannot fail a build.
#
# WHY IT IS STATIC AND NOT A DRIVEN TEST: a press-fired button and a
# release-fired one are THE SAME PIXELS in every still. The difference exists
# only while a physical button is held, and no screenshot-driven row holds one
# down - which is why this survived ten packages. The driven test is worth
# having too (tests/dosbtn.py), and it is not what catches the eleventh package.
