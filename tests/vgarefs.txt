# tests/vgarefs.txt - every reference from outside the VGA rung INTO it, and
# the test that keeps a machine with neither a VGA nor an EGA out of it.
# Enforced by tools/os88ovlchk.py rule 2f.
#
# WHY THIS FILE EXISTS
#
# `.vga` (docs/plans/MOVABLE-COLD-PLAN.md 2, SPEC.md 2.10.9) is the code only a
# VGA or an EGA runs. It sits inside KERNEL_SEG's 64KB window, so `.text` calls
# it with the near calls it always used - and on a machine whose [vid_avail]
# has neither VID_A_VGA nor VID_A_EGA, kmain_o slides `.cold` down over it at
# boot. From then on a call into the rung runs `.cold`'s bytes as whatever
# they decode to. Nothing faults where the mistake is: the call assembles, the
# VGA rows pass, and a Hercules machine goes wrong somewhere later.
#
# So the surface is registered rather than trusted, as tests/ovlrefs.txt does
# for the boot overlay. A NEW reference fails the build until somebody writes
# down the answer to one question:
#
#     WHAT KEEPS A MACHINE WITH NEITHER CARD FROM GETTING HERE?
#
# The answer has to be a RUN-TIME test. `%ifdef GFX_VGA` is not one: kern_big
# defines it on every machine, a Hercules included. [vid_avail] is fixed for
# the life of the machine; [vid_planes] = 4 and [vid_mono] = 0 describe the
# display being drawn on, and no display a machine without either card has can
# be planar - so both answer the question, and so does any path that only
# starts inside one of them.
#
# The list may shrink freely - delete the row with the code. A row here that
# no longer has a reference is itself a build failure.
#
# FORMAT: <symbol>   <the guard>

# --- gfx_blit4's planar arm (vga12.inc) --------------------------------------
# entered at `.vga` only on [vid_planes] = 4, or [vid_mono] = 0 without VID_EXT
vga_p4build     gfx_blit4's planar arm: [vid_planes] = 4, once a boot
vga_blit_span   gfx_blit4's planar arm: [gfx_blit_fst] = 2 is set only there
vga_blit_prow   gfx_blit4's planar arm: the decoder's handover is armed only there ([gfx_blit_pok])

# --- the doors (vga12.inc) ----------------------------------------------------
gfx_blitp_v     gfx_blitp's door: [vid_avail] & (VID_A_VGA | VID_A_EGA), else CF = 1
